## 2. Ölçüt karşılaması (üç bacak)

**(a) "hedef+limit ver → gece tur serisi"** — CLI `node src/cli.ts gece --hedef "..." --limit N
[--interval-ms N] [--tazelik-dk N]` + `geceModu` sürücüsü (core/src/gece.ts, YENİ 186 satır):
runDaemon'i SARMALAR (ince kanca: runTick sarmalayıcı + shouldStop köprüsü + spawnCliTick export —
daemon çekirdeğine sıfır davranış dokunuşu). Tur serisi ölçülür: her tur `gece-turu` kaydı
(fsync'li jsonlEkle) + kapanışta `gece-kapanis` kaydı (turSayisi/ok/failed/toplamMs/ortalamaMs/
reason). Kanıt: A4-3 (3 tur, limit-doldu, ort 120 ms), A4-4 (defter: 3 gece-turu + 1 gece-kapanis,
alanlar tam — DİSKTEN geri okunarak), A4-5 (100+300 → ort 200), A4-9 (karışık 0,1,0 → ok 2
failed 1). Doğrulama RED'leri: A4-10 (hedef boş / turLimiti 0 / kanıt defteri yolu boş → döngüye
girilmez, her RED kendi kapanış kaydını düşürür — "neden açılmadı" da kalıcı bilgi).

**(b) "rozet yeşilse açılır"** — açılış kapısı: `unattendedReadinessBeslemeli` (A0-3'ten, "A4
tüketir" ucu) 'gozetimsiz-hazir' değilse gece AÇILMAZ (0 tur, RED). Canlılık: her tur sonrası rozet
yeniden okunur; kırmızıya düştüyse seri kendini kapatır ('rozet-kapandi' — koruma davranışı, code 0;
daemon koşarken kanıt eskirse gece kendiliğinden kapanır, A0-3 fail-closed canlılık sözü). Kanıt:
A4-1 (kırmızı rozet → 0 tur RED + kapanış kaydı), A4-2 (gerçek rozet entegrasyonu: 6 bayrak besli
+ taze DB → 6/6 koşul geçer), A4-6 (tur ortasında rozet kırmızıya düşer → 1 tur sonra durur,
reason rozet-kapandi), A4-8 (3 üst üste kırmızı çocuk → fail-closed, nonzero, 3 tur denetim izi),
A4-11 (bütünleşik: gerçek rozet + gerçek DB, enjeksiyonsuz rozetOku). Tazelik penceresi default
30 dk (CLI --tazelik-dk ile ayarlanır); daemon kanıt beslemesi (A0-3) koşarken pencere canlı kalır.

**(c) "+100 test"** — testLoc 100 (graf ölçüsü satır-LOC): gerçek `core/test/a4-gece.test.ts`
**281 satır / 11 test**; süit 450 → **461** (package.json test dizisi +1 giriş). Yorum dürüst:
graf SSOT'ta test SAYISI ayrı sayısal hedef belirtilmemiş — ölçüt satır bazlı okundu ve 281 ≥ 100
karşılar; 11 test ölçüt-kapsamının (üç kapı × doğrulama/canlılık/limit + defter + gerçek-rozet
bacakları) kendi testlerini doğurmasıyla şekillendi (A3/A0-2/A0-5 deseni — aşağıdaki dürüst not a).
