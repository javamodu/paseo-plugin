# K-0017 — Gelen Kutu kanalı (ajanlar arası bulgu taşıma) (ONAYLANDI 2026-10-12)

## Bağlam
Dış ajan/subagent bulguları kullanıcının kopyala-yapıştırıyla giriyordu; şema/adres/dedupe yoktu, geri-bildirim döngüsü kapalı değildi. Reviewer taşıma katmanını 4/10 ölçtü; coder doğruladı. K-0014'e katılmadı (donmuş deneye altyapı sokulmaz).

## Karar
- Tek kanal: `raporlar/gelen-kutu/<kaynak>-<YYYY-MM-DD>.md` + aynı adlı `.json` sidecar. Kaynak başına dosya + append-only (aynı kaynak aynı gün iki kez yazarsa aynı dosyaya EKLER; rewrite yok).
- Şema (sidecar, zorunlu alanlar): `schemaSurum: 1` + maddeler: { id, baslik, dosyaRef, etiket: (R)|(T)|*, siddet, oneri, islenme: null }. İşlenince maddeye `islenme: { durum: "kabul"|"red", hash: "<commit>", ts }` append edilir — kapanış kanıtı commit hash'idir; (*)→(R) yükselmesi ancak kanıtla.
- Sert kural: dış bulgu (*) girer, repo-doğrulamasıyla yükselir; dedupe kapısı (K-0013 madde 4) burada da geçerli.
- Tek yazıcı disiplini korunur: dış/subagent yalnız gelen-kutuya yazar; coder işler.
- Mezarlık freni: bekçi "24s işlenmemiş gelen-kutu maddesi" anomalisi (v0.10.1) + açılış echo'suna "gelen-kutu tara" adımı (ÇEKİRDEK).
- Şema kapısı: saglik.ps1 gelen-kutu sidecar'larını doğrular (JSON parse + schemaSurum=1).
