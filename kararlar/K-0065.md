# K-0065 — SPAWN KÖPRÜSÜ PARİTESİ: panel + düğmesi zincirden spawn (K-0060 uygulaması)

Tarih: 2026-11-04 · Tür: mimari karar (operatör onaylı) · Durum: ONAYLANDI — DALGA SIRASI YÜRÜRLÜKTE

## Bağlam

Operatör talebi (verbatim, 2026-11-04): «proje adının üstüne gidince artı ile yeni oturum açma özelliği olmalı .. ayrıca projelerin üstünde new workspace açılıp composer menüsünde proje için klasör seçilebilmeli yada add project ile klasör oluşturulmalı .. aynı paseo ide davranışı ..» — onay (verbatim): «tamam bu şekilde yap». Mevcut gerçek: panel salt-okur GET + token kapılı mesaj POST (D8'de uçtan uca kanıtlı); spawn bugün yalnız KURMAY MCP (`create_agent`, parent-agent-id'li) veya operatörün Paseo IDE'de manuel açması (parent'sız, 606 kayıt). K-0063 §2: köprü açılana kadar KURMAY MCP ile spawn, panel yönlendirme yüzeyi.

## Karar

1. **+ düğmesi KENDİ spawn ETMEZ — spawn TALEBİ düşürür.** Zincir: operatör → panel `POST /api/spawn-talebi` (token kapılı, fail-closed) → talep diske (kuyruk) + KURMAY-1'e iletilir → **KURMAY MCP `create_agent` işletir** (parent-agent-id'li soy kayıt + brif EK-3) → sonuç diskte → panel diskten okur (SSOT). Panel sunucusu ajan süreci YÖNETMEZ.
2. **Bileşenler sırayla, her biri atomik dalga:** (1) proje başlığına hover → + → yeni oturum talebi [Dalga B: server ucu + test · Dalga C: hover düğmesi + canlı DOM + restart] → (2) new workspace → (3) composer'da proje klasörü seçimi → (4) add project ile klasör oluşturma. Her dalga tam kapı test EXIT 0 ile kapanır (K-0062 tavanları: net <+200, ≤4 koşu).
3. **Başlatma:** operatör «tamam bu şekilde yap» bu karar için START'tır (K-0063 §4 bu iş kapsamında karşılandı); genel ordu dalgası sırası (ARŞİV → FAZ-V → pilot) bu karardan bağımsız devam eder.

## Reddedilen alternatifler

- **Panel sunucusu CLI ile doğrudan spawn** (`paseo run` çağrısı) — parent-agent-id YAZILMAZ → K-0063 §2 zincir kopar; kill/brif/kanıt denetimi KURMAY'dan panele dağılır (otorite ekseni altyapı eksenine karışır — GLOSSARY §2).
- **Panelin daemon'u doğrudan yönetmesi** — daemon zemin, yönetici değil; panel = görünüm + talep yüzeyi (GLOSSARY §2 otorite/altyapı ayrımı).
- **+ düğmesinin senkron spawn beklemesi** — ajan süreç spawn'ı asenkrondur; panel talebi düşürüp dürüst durum gösterir («kuyrukta / işlendi / ajan görünür»), sahte «açıldı» dönmez (E10).

## Sonuç / uygulama

Dalga B: `pano/server.js` POST ucu (token zinciri mevcut mesaj ucunun deseni: 401/400/429 fail-closed; talep append-only kuyruk dosyası) + test süiti. Dalga C: `pano/ordu-panosu.html` hover+ düğmesi + uca bağlanma + canlı DOM doğrulama + izole 4937 restart ([insan] onay adımı dalga içinde). Bileşen (2)-(4) ayrı dalga brifleriyle; tamamı PANEL-DALGA-SIRASI'na kaydedilir.
