# K-0019 — Pano İskelet Sistemi (TASLAK 2026-10-12 — kullanıcı onayı bekleniyor)

## Bağlam
60-repo evreninde telemetri .verimlilik/ altında dağınık; görsel pano yok (proje-panosu.ps1 md/json üretir, canlı değil). 23-repo drift deneyi (K-0014) jenerasyon varyansını kanıtladı: ajan her seferinde farklı UI üretir → sıfırdan yazım YOK. Prensip: **sabit iskelet + ince config** (ajan üretmez, doldurur).

## Karar
1. **İskelet:** `plugin/pano-iskelet/` altında tek-dosya vanilla HTML+JS, hash-router (#/doktor vb.), build yok. Dosya TS modülüne gömülür (bundle CJS+eval kısıtı — DERSLER: import.meta/__dirname yasak). Sunucu yoksa salt-görüntü degrade (son veri.json gömülü gösterilir).
2. **Mini uç (plugin server, node:http, bağımlılıksız, 127.0.0.1:4377):**
   - `GET /` → iskelet HTML
   - `GET /api/veri?repo=X` → birleşik veri.json (**TTL önbellek ≥60sn şart** — 23-repo tam tarama ~50sn sürer, her istekte tarama YASAK)
   - `POST /api/emir` → dar-liste (sunucu-baslat/durdur, ajan-görevlendir, mod-değiştir — serbest metin YOK) · ADMIN_TOKEN yoksa fail-closed (browser-bridge deseni)
   - `GET /api/canli` → SSE itme (istemci reconnect backoff'lu)
   - Port çakışması: dinleyici contribute() cleanup remover'ına kaydedilir (reload güvenli — SDK deseni doğrulandı).
3. **Sekmeler:** 1) Doktor (açılış) 2) Orkestrasyon (K-0020) 3) Canlı önyüz (workspace script proxyUrl embed + Başlat/Durdur) 4) Galeri (mockup HTML+PNG kartları) 5) Arka yüz.
4. **Doktor metrikleri:** LOC hızı · biten/sıradaki görevler · teknik borç (TODO/1k LOC) · mimari drift (god-file + katman-ihlal sayacı) · FAKE-GREEN probu (3 proxy: test/assert oranı düşüşü, kod değişti-test değişmedi, skipped sayısı) · Lighthouse/CWV (web reposunda; şema N/A destekler) · plugin/sözleşme uyum+trend (SES/SKS) · günlük token in/out + istek + çalışma saati · doc↔kod↔plan hizası · atıl kod/doküman yükü · kod kalitesi · plan kalitesi (plan↔kod drift + onay bekleyen karar yaşı).
   **Dürüstlük kuralı:** "kalan LOC" YAZMAZ — yerine "kalan görev + (T) efor".
5. **Sol panel (kullanıcı eki):** üstte minimal Lighthouse/SEO/CWV metrik şeridi (web repo ise; değilse N/A rozeti) + genel sağlık rozetleri (teknik borç · mimari drift · fake-green · doc↔kod↔plan · plugin uyumu — her biri tek satır OK/SARI/EKSIK/N-A). Bu rozetler orkestrasyon sekmesinde de aynı bileşenle görünür (tek kaynak).
6. **Veri:** veri.json şeması `schemaSurum: 1` + saglik şema kapısı + bekçi iskelet-hash kontrolü (kopya drift'i). Toplayıcı: proje-panosu.ps1 genişler (mevcut TelemetriOzet + KovaBul üstüne).
7. **Ölçek:** workspace seçici + lazy sekme (23 repo şişmesin — veri repo bazlı sayfalanır). Pilot: chinese-hsk + txt-to-cad.

## Reddedilen alternatifler
- React/framework ile UI: build zinciri gerektirir; iskelet prensibine aykırı (jenerasyon varyansı).
- Plugin client ekranı (client/): React Native + DOM yasağı zengin tablo/gösterge için dar; http servis bağımsız tarayıcıda çalışır.
- İstek başına canlı tarama: 50sn/repo-evreni maliyeti — TTL önbellek seçildi.
- Merkezi sunucu (tüm makineler): tek makine yerel yeterli; 127.0.0.1 bind sınırı korunur.

## Sonuç / riskler
- Bağımlılık sıfır (node:http + gömülü HTML) · reload güvenliği cleanup deseniyle · token yoksa yazma kapalı.
- Risk: gömülü HTML büyürse bundle şişer (~40KB üstünde izle) · SSE bağlantı sayısı sınırlı tutulur (sekme başına 1).
- Uygulama v0.12 konusu, ayrı onay ister.
