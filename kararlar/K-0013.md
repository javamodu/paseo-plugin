- Bağlam: Elle yürütülen dış-review döngüsü kanıtlı değer üretti (K-0002, K-0008, K-0009, K-0011) ama emek-yoğun ve kesikli. Reviewer önerisi + coder 4 şartı + kullanıcı onayı.
- Bekçi (A): paseo-verimlilik plugin modülü, LLM'siz. KÖPRÜ yaklaşımı: saglik.ps1 + zincir-kontrol.ps1'i child-process çağırır, SONUC satırını parse eder — yeniden yazım yok (duplike sonHandoff dersi). - Bekçi nüansı (enstrümantasyon ≠ müdahale): kontrol kohortunda yalnız repo-agnostik telemetri anomalisi; köprü kontrolleri (saglik/zincir) yalnız sözleşmeli repolarda.
- Dedupe tanımı: bulgu başlığı normalize (küçük harf, noktalama sıyrık) → son 4 haftanın raporlar/sozlesme-sondaj/*/sonuc.json başlıklarıyla karşılaştır; eşleşmede yeni kayıt yok, sayaç artar.
- Schedule idempotency: repo yolu + schedule adı bazlı; varsa dokunulmaz (çok-repo birikimi engeli).
- Sondaj pilotu: sorular/banka.md (A onboarding / B çelişki / C stres / D doğrulama tuzağı / E regresyon / F kullanıcı tekrarı) + haftalık create_schedule; çıktı raporlar/sozlesme-sondaj/<tarih>/OZET.md + sonuc.json. İlk 3 koşu baseline.

- Triage kapısı: doğrulanamayan iddia otomatik (T)'ye düşer; sözleşme ailesine otomatik yazma YOK — kabul yalnız kullanıcı onayıyla yeni K kaydı.
- Kapanış kriteri: plugin testleri yeşil + canlı drift tatbikatı (kasıtlı kirli dosya → alarm) kanıtı.
