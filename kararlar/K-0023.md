# K-0023 — Sondaj Ö1+Ö2 Metin Düzeltmeleri (ONAYLANDI 2026-10-12 — PLAN-eksik-kapatma onayı)

## Bağlam
Sondaj pilotu (raporlar/sozlesme-sondaj/2026-10-12): B1'de %90 acil-damga ↔ okumadan-yazma yüzeysel çatışma okuması (kapsam ayrımı metinde var ama görünür değil); C1'de STATE_BOARD kirli-dosya notunun untracked bekçi raporunu kapsamadığı sapması (düşük şiddet) — yalnız panoya güvenen devralan ajan drift dosyasını kaçırır.

## Karar
1. **Ö1:** ÇEKİRDEK ve REHBER §2 %90 maddesine yarım cümle: "(durum dosyasına; kod yazımı okumadan-yazma kuralına tabi kalır)".
2. **Ö2:** `server/bekci.ts` takip raporu üretiminde STATE_BOARD aktif-iş notuna untracked dizin işaretçisi düşülür (raporlar/takip-sozlesme/ gibi); alternatif olarak rapor başlığına kalıcı not.

## Reddedilen alternatifler
- B1'i kural metnini genişleterek çözmek: kural bütçesi (77>40 SARI) altında metin şişmesi reddedildi; yarım cümle yeterli.
- C1'i bekçi raporunu tracked yaparak çözmek: raporlar append-only akışına kirli-ağaç bağımlılığı ekler; işaretçi daha ucuz.

## Sonuç / riskler
- Doğrulama: saglik exit 0 + sondaj koşusu 2/3'te C1 tekrarı gözlenmez.
- Kapsam: ÇEKİRDEK 1 yarım cümle + REHBER 1 yarım cümle + bekci.ts ≤1 dosya.
- Risk: yok denecek; metin değişikliği enjeksiyon bytes bütçesini izlemeyi gerektirir (≤8KB freni).
