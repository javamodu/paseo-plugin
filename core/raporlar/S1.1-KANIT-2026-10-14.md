## Akis adimlari (hepsi gercek fonksiyon; ucretli/dis API YOK, Paseo YOK)

1. `openStore()` + `setGlobalStop(false)` — defter acilir, stop latch kapali.
2. `createRunPlan(...)` — capsule + DONMUS plan (plan_hash) + run + node TEK transaction (A01/A02).
3. `ensureStartCommand` + `approvePlan(...,'human')` — insan onayi; onaysiz `readyNodes` bos / dispatch RED (A03).
4. `dispatchNode(...)` — attempt + outbox + rezervasyon tek tx (A04/A06); handoff DTO zorunlu (P1 §5).
5. `processOutbox(db, new LocalRuntimeAdapter(localProbe, EchoLauncher, {ORDU_RUNTIME:'local'}))` — YEREL worker: gercek `node -e` alt-sureci candidate dosyasini yazar, pid registry'ye yazilir, `SESSION_BOUND` (`external_session_id = local:<pid>`).
6. `commitCandidate(attempt, fence=1, sha256(icerik))` — aday dondurulur (A10/A36).
7. `evaluateAttempt(..., realRunner)` — BAGIMSIZ evaluator: allowlist disi komut kosmaz (A11/M19); gercek `execSync` ile fixture kosar; PASS = exit-0 + protokol {tests>0,failed:0} (A13); kanit yalniz donmus adaya + guncel fence ile yazilir.
8. `settleNodeOutcome(PASS)` -> node DONE; `allNodesDone` true.
9. F2-A: `requireReceiptLinks` — receipt'in 14 zorunlu alani sema + 8 semantik bag (run/attempt/candidate/evaluator/environment/plan-policy/grant/fence) STORE SORGUSUYLA dogrulanir. Tamper kolu (testCounts bozuk) RED.
10. `requestDelivery(run,'human', reasoningReceipt)` — M18 makbuz kapisi (aday + gercek PASS evidenceRefs baglari) -> `requestAcceptance`.
11. `decideApproval(APPROVED,'human',1)` — donmus adayda gercek PASS kanit sart; run `ACCEPTED` + `RUN_ACCEPTED` eventi.

## Event zinciri (canli kosudan, sequence sirasi)

STOP_LATCH_CLEARED -> CAPSULE_CREATED -> PLAN_PROPOSED -> RUN_CREATED -> COMMAND_ACCEPTED -> PLAN_APPROVED -> DISPATCH_RESERVED -> SESSION_BOUND -> CANDIDATE_FROZEN -> EVIDENCE_RECORDED -> BUDGET_SETTLED -> APPROVAL_REQUESTED -> APPROVAL_DECIDED -> RUN_ACCEPTED
